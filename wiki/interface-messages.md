# Interface messages changed on the wiki

Some labels are changed by editing a `MediaWiki:` page on the wiki itself (as Wikipedia does).
Those edits live in the wiki's database, not in this repo, so they are listed here.
If the database is ever rebuilt from scratch, recreate them (as an admin).

| Wiki page | Set to | Why |
|---|---|---|
| `MediaWiki:Talk` | `Talk` | Talk tabs say "Talk" instead of "Discussion", like Wikipedia |
| `MediaWiki:Vector-night-mode-beta-tag` | *(empty)* | The Appearance menu says "Color" instead of "Color (beta)" |
